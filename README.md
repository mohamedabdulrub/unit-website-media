# Unit website media

Short looping videos and transparent animations used on [unitfood.co](https://www.unitfood.co), served via the jsDelivr CDN:

`https://cdn.jsdelivr.net/gh/mohamedabdulrub/unit-website-media@main/video/<file>.mp4`

- `video/` - H.264 MP4, muted loops (hero, reels, menu tiles)
- `anim/` - VP9 WebM with transparency (Unitverse character animations)

Photos and Safari animation fallbacks are hosted in the Squarespace asset library.
